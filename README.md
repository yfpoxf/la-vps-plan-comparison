### 不限量和流量包，算一次就知道选哪个

标称 30Mbps 比 20Mbps 快，但流量包给它设了上限。按理论满速跑：

- 20Mbps 不限量：跑满一个月约 6.4TB。
- 30Mbps + 1TB：满速约 3.2 天就把 1TB 用完，剩下的日子要么限速要么停。
- 100Mbps 不限量：跑满一个月约 32TB。
- 200Mbps + 1TB：满速约 11.7 小时。

这些是理论值，实际受对端带宽、路由和时间段影响，会低不少。但量级差得很明显。「不限量」档端口小，抵不住它细水长流；「1TB」档端口大，抵不住它三天就见底。

用途是持续传输（备份、同步、镜像、中转），选不限量的那一档，端口小点无所谓。用途是建站、跑 API、偶尔传文件，流量包那档的高端口更值，因为你的业务本来也不会一直满速跑。

不限量通常附带公平使用条款，真有大量持续占用，商家可能会按条款处理，动手前问一句实际限速规则。
